# Hello Git

## Objectif
Créer une page web simple pour découvrir Git et GitHub.

## Technologies utilisées
- HTML
- CSS
- Git
- GitHub

## Instructions pour ouvrir la page
1. Ouvrir le dossier du projet.
2. Ouvrir le fichier index.html avec un navigateur.

## Évolutions du projet
- Création de la page Hello Git.
- Modification du texte et du style.
- Création de branches et résolution d'un conflit.
